# Instagram Clone 📸

A social media application built using Flutter, inspired by Instagram.

## ✨ Features

- Instagram-inspired user interface
- Clean and minimal design
- Built with Flutter and Dart

## 🛠️ Technologies Used

- Flutter
- Dart
- Firebase
- cloudinary
